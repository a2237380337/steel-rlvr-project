# DPO 阶段实验协议（历史对照）

本文记录最初的固定偏好对实验，便于复核 DPO 为什么没有超过 SFT。当前采用的
在线 RLVR 方法、数据隔离、训练配置和最终指标见
`reports/posttraining_search_20260802.md`。

## 研究问题

1. 在完全不使用低频测试钢种标签的条件下，DPO 能否继续改善 LoRA-SFT 的数值生成误差？
2. 只改变训练偏好对的钢种频次抽样权重，是否能改善 Macro-MAE 和 Worst-group MAE？

这是历史监督数据上的离线后训练实验，不是在线轧机控制。

## 数据隔离

1. 原始 34,318 行中排除 1 条字段占位记录，保留 34,317 条真实记录、63 个钢种。
2. 44 个常见钢种按 seed 42 做 8:2 训练/验证；同一原始记录的三个道次不跨分区。
3. 19 个频次低于 50 的钢种整组进入测试，共 339 条原始记录、1,017 条道次样本。
4. 训练中位数、MAD、物理边界和钢种频次只由训练标签计算。
5. 测试标签不参与 SFT、偏好对构造、checkpoint 选择或超参数调整。
6. Pass1/2/3 prompt 只包含当前道次决策时已经可观测的信息。

训练/验证/测试 JSONL SHA256 固定在 `data_report.json`；正式准备数量不符时直接失败。

## 偏好对

- 完整池：训练 81,546 对，验证 20,388 对；
- `chosen`：观测目标组成的严格 JSON；
- `rejected`：同格式 JSON，数值确定性偏移 `0.5/1.0/1.5 × train_MAD`；
- 相同 prompt 的 chosen/rejected 不能相等；
- 测试集不生成偏好对。

正式 DPO 训练按 Pass1/2/3 各抽 1,000 对，共 3,000 对；验证按道次各抽 256 对，共 768 对。

## 固定对照

| 组别 | 方法 | 作用 |
|---|---|---|
| A | CAC submitted KD-Steel | 相同场景的外部 baseline |
| B | Qwen3.5 Base | 未后训练语言模型 |
| C | LoRA-SFT | 监督后训练基线 |
| D | SFT + DPO | 均匀抽取偏好对 |
| E | SFT + 频次感知 DPO | 项目消融 |

D/E 共用同一个 SFT 起点、冻结 SFT 参考模型、seed、3,000 条训练对、768 条验证对、200 steps、`beta=0.1`、学习率和优化器。唯一方法差异是训练对抽样权重：

```text
w_g = clip(sqrt(200 / n_g_train), 1, 2)
```

因此两组训练样本不要求相同；它们的道次配额相同，验证样本和顺序完全相同。普通/频次感知组的加权样本占比为 7.93%/10.63%。

## 指标与 checkpoint

- 主指标：总体 MAE、R²；
- 长尾指标：`道次 × 钢种` 等权 Macro-MAE、Worst-group MAE；
- 完整性：数值可解析率、严格 JSON 率、物理越界率；
- 训练诊断：DPO validation loss、偏好准确率、运行时间和峰值显存。

SFT/DPO 均只看 validation loss 选模型。正式测试在模型与超参数冻结后一次性运行。无法解析的输出不删除，而是用训练集道次中位数回填并计入主指标。

## 正式结果

- SFT 总体 MAE 0.6486，相对 Base 0.6864 降低 5.52%；
- 普通 DPO MAE 0.6488，相对 SFT 回退 0.03%；
- 频次感知 DPO 与普通 DPO 的总体/Macro/Worst-group MAE 完全相同；
- 两个 DPO adapter 权重不同，但 1,017 条测试样本的贪心数值输出完全一致；
- DPO/频次感知 DPO 的严格 JSON 率为 99.12%/99.02%，数值可解析率均为 100%，物理越界率为 0；
- 所有总体 R² 仍为负，单随机种子不足以判断统计显著性。

结论是固定偏移负样本没有把训练偏好准确率转化为低频钢种回归增益。该结果保留为受控负实验，不写成性能提升。
